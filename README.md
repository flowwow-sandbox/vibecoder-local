# Песочница flowwow — твой первый прототип

Это шаблон для вайбкодинга. Ты не пишешь код руками — ты словами объясняешь, что хочешь, а агент делает.

## Как начать

1. Открой эту папку в Claude Code или Codex.
2. Напиши агенту: «запусти онбординг».
3. Дальше агент всё объяснит и проведёт сам.

Если застрял — открой [sandbox.flowwow.co/learn](https://sandbox.flowwow.co/learn) или пиши в канал «Песочница».

## Что здесь уже настроено

Кроме инструкций для агента в шаблоне лежит защитный слой: guard-хуки (`.claude/hooks/`, нужен `python3`) останавливают опасные команды — `rm -rf /`, force-push, чтение `.env`, запись за пределы проекта; pre-commit hook прогоняет gitleaks перед каждым коммитом; `.npmrc` и `uv.toml` не дают ставить пакеты моложе 7 дней.

Если хук что-то заблокировал, он объясняет причину прямо в ответе агента — журнала на диске нет, шаблон ничего не пишет за пределами папки проекта.
